The problem

Keyword search misses what travellers actually mean

Traditional accommodation search forces you to guess the right words. "Cozy" returns nothing if the listing says "intimate." "Near the beach" misses places that describe sunrise views over the ocean.

This project replaces keyword matching with semantic vector search — encoding both queries and listings as dense numerical representations, so meaning is matched, not just words.

A LangGraph ReAct agent orchestrates the search, fetches structured listing details, applies guardrails, and synthesises a recommendation — all observable through LangSmith traces.

Five phases
01

Data Pipeline

Raw Airbnb dataset ingested and transformed with PySpark on Databricks, catalogued with Unity Catalog.

Databricks
02

Vector Embeddings

Listing descriptions encoded into 384-dimensional vectors using BAAI/bge-small-en-v1.5, stored in Supabase with pgvector HNSW indexing.

pgvector
03

AI Agent Layer

LangGraph ReAct agent with two tools — semantic search and structured detail fetch — powered by DeepSeek via OpenAI-compatible API.

LangGraph
04

Guardrails & Observability

Custom input/output validation layer for toxicity, off-topic queries, and competitor mentions. Full trace visibility through LangSmith.

LangSmith
05

Deployment

Containerised with Docker, CI/CD via GitHub Actions, hosted on Azure Container Apps with a live public endpoint.

Azure
